# Add / Edit Product — Wireframe (ASCII)

This document defines the **wireframe-level structure** for a modern, scalable **Add / Edit Product** page designed for shadcn/ui.
It focuses purely on **layout, hierarchy, and UX flow** — no styling or code.

---

## GLOBAL PAGE SHELL

```
┌─────────────────────────────────────────────────────────────────────┐
│ ← Products   Add Product                                  [ Draft ] │
│                                                             ⋮       │
│                                              Save Draft  Publish    │
└─────────────────────────────────────────────────────────────────────┘
```

- Sticky header
- Status as badge
- Primary actions centralized
- Overflow menu for destructive actions

---

## PRIMARY NAVIGATION (Tabs)

```
┌─────────────────────────────────────────────────────────────────────┐
│  [ General ]  [ Pricing & Inventory ]  [ Media ]  [ Variants ]  [ SEO ] │
└─────────────────────────────────────────────────────────────────────┘
```

Each tab represents a single merchant task.
